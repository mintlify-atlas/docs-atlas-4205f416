---
title: "Parking Lots"
description: "Create and retrieve parking lots (parqueaderos) associated with a company."
---

All endpoints require a valid JWT in the `Authorization` header.

<Note>
  A parking lot belongs to exactly one company (`idEmpresa`). Create the company first before registering parking lots.
</Note>

---

## POST /api/parking-lots

Create a new parking lot and associate it with an existing company.

**Request body**

<ParamField body="nombre" type="string" required>
  Name of the parking lot. Minimum 3 characters.
</ParamField>

<ParamField body="capacidadTotal" type="number" required>
  Total number of spaces (cells) this parking lot can hold.
</ParamField>

<ParamField body="ubicacion" type="string" required>
  Physical address or location description. Minimum 5 characters.
</ParamField>

<ParamField body="idEmpresa" type="number" required>
  ID of the company that owns this parking lot.
</ParamField>

**Response**

<ResponseField name="id" type="number">
  Unique identifier of the newly created parking lot.
</ResponseField>

<ResponseField name="nombre" type="string">
  Name of the parking lot.
</ResponseField>

<ResponseField name="capacidadTotal" type="number">
  Total capacity.
</ResponseField>

<ResponseField name="ubicacion" type="string">
  Location of the parking lot.
</ResponseField>

<ResponseField name="idEmpresa" type="number">
  ID of the owning company.
</ResponseField>

**Example**

```bash
curl -X POST http://localhost:3000/api/parking-lots \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"nombre": "Parqueadero Central", "capacidadTotal": 50, "ubicacion": "Calle 10 # 5-20, Bogotá", "idEmpresa": 1}'
```

```json
{
  "id": 3,
  "nombre": "Parqueadero Central",
  "capacidadTotal": 50,
  "ubicacion": "Calle 10 # 5-20, Bogotá",
  "idEmpresa": 1
}
```

## GET /api/parking-lots/empresa/:idEmpresa

Retrieve all parking lots belonging to a specific company.

**Path parameters**

<ParamField path="idEmpresa" type="number" required>
  ID of the company whose parking lots to list.
</ParamField>

**Response**

Returns an array of parking lot objects.

<ResponseField name="id" type="number">
  Unique identifier of the parking lot.
</ResponseField>

<ResponseField name="nombre" type="string">
  Name of the parking lot.
</ResponseField>

<ResponseField name="capacidadTotal" type="number">
  Total capacity.
</ResponseField>

<ResponseField name="ubicacion" type="string">
  Location of the parking lot.
</ResponseField>

<ResponseField name="idEmpresa" type="number">
  ID of the owning company.
</ResponseField>

**Example**

```bash
curl http://localhost:3000/api/parking-lots/empresa/1 \
  -H "Authorization: Bearer <token>"
```

```json
[
  {
    "id": 1,
    "nombre": "Parqueadero Norte",
    "capacidadTotal": 30,
    "ubicacion": "Av. 68 # 12-40, Bogotá",
    "idEmpresa": 1
  },
  {
    "id": 3,
    "nombre": "Parqueadero Central",
    "capacidadTotal": 50,
    "ubicacion": "Calle 10 # 5-20, Bogotá",
    "idEmpresa": 1
  }
]
```

## GET /api/parking-lots/:id

Retrieve details for a single parking lot by its ID.

**Path parameters**

<ParamField path="id" type="number" required>
  ID of the parking lot.
</ParamField>

**Response**

<ResponseField name="id" type="number">
  Unique identifier of the parking lot.
</ResponseField>

<ResponseField name="nombre" type="string">
  Name of the parking lot.
</ResponseField>

<ResponseField name="capacidadTotal" type="number">
  Total capacity.
</ResponseField>

<ResponseField name="ubicacion" type="string">
  Location of the parking lot.
</ResponseField>

<ResponseField name="idEmpresa" type="number">
  ID of the owning company.
</ResponseField>

<Warning>
  Returns `404 Not Found` if no parking lot exists with the given `id`.
</Warning>

**Example**

```bash
curl http://localhost:3000/api/parking-lots/3 \
  -H "Authorization: Bearer <token>"
```

```json
{
  "id": 3,
  "nombre": "Parqueadero Central",
  "capacidadTotal": 50,
  "ubicacion": "Calle 10 # 5-20, Bogotá",
  "idEmpresa": 1
}
```
