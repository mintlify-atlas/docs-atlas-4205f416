## Overview

Reports in Parkontrol provide a record of parking lot activity for a given time period. Each report is scoped to a single parking lot and a specific period (e.g., daily, weekly, or monthly), and can reference an external file — such as a spreadsheet or PDF — via a URL.

Reports are an administrative feature used to document and archive operational data across facilities.

<Info>
  Access to reports is restricted to users with the **Administrator** role.
</Info>

## Creating a report

<Steps>
  <Step title="Navigate to Reports">
    Open the **Reports** section from the main navigation.
  </Step>
  <Step title="Click to create a new report">
    Initiate the report creation flow. You will be asked to provide the required fields.
  </Step>
  <Step title="Fill in the required fields">
    Two fields are required to create a report:

    - **Parking Lot** (`idParqueadero`) — The lot the report covers. Must be a valid, registered parking lot.
    - **Period** (`idPeriodo`) — The time period the report covers. Periods are pre-configured in the system (e.g., daily, weekly, monthly).

    One field is optional:

    - **File URL** (`urlArchivo`) — A link to the report file (e.g., a hosted CSV, PDF, or spreadsheet). This can be left blank at creation time and updated later.
  </Step>
  <Step title="Submit">
    The report is saved and appears in the reports list for the selected parking lot.
  </Step>
</Steps>

## Viewing reports

Reports are filtered by parking lot. To view reports for a specific facility:

1. Select the desired parking lot from the filter.
2. The list updates to show all reports associated with that lot, returned via `GET /reports/parqueadero/:idParqueadero`.

Each report record shows:

| Field | Description |
|-------|-------------|
| ID | Unique report identifier |
| Parking Lot | The lot this report belongs to |
| Period | The time period covered by the report |
| File URL | Link to the external report file, if one has been attached |

To retrieve a single report by its ID, use `GET /reports/:id`.

## Report file URLs

The `urlArchivo` field links a report record to an externally hosted file. This is useful when reports are generated by an external tool (such as a BI platform or spreadsheet export) and stored in cloud storage.

### Attaching or updating a file URL

You can set or update the file URL for an existing report after it has been created:

<Steps>
  <Step title="Identify the report ID">
    Find the report in the list for the relevant parking lot and note its ID.
  </Step>
  <Step title="Send a PATCH request">
    Call `PATCH /reports/:id/url` with the body `{ "urlArchivo": "https://your-storage/report.pdf" }`. The `urlArchivo` field accepts strings up to 255 characters.
  </Step>
  <Step title="Confirm the update">
    The response returns the updated report object with the new URL attached.
  </Step>
</Steps>

<Tip>
  Set the `urlArchivo` immediately after generating a report file so that anyone reviewing the report list can access the underlying data directly from the record.
</Tip>

<Warning>
  Parkontrol stores only the URL reference — it does not host or manage the file itself. You are responsible for ensuring the linked file remains accessible at the provided URL.
</Warning>

## Who can access reports

Only users with the **Administrator** role can create, view, and update reports. Operators do not have access to the Reports section.

For a full breakdown of role permissions, see [User roles](/administration/user-roles).
